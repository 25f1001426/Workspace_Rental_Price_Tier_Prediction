#1. Data preprocessing is the process of cleaning, transforming, and organizing raw data into a structured format so that machine learning algorithms can analyze and learn from it effectively.
  On the basis of the EDA done for the given dataset following preprocessing steps are required:
     1.Handle missing numerical values
     2. Handling missing categorical values
     3. Encoding categorical values
     4. Converting date columns
     5. Some feature engineering
#2. There are no duplicate rows or columns present in the training or testing dataset.
For missing numerical values we will use median imputation fitted on the training split. The median is robust to skewed distributions and extreme values.
Missing borough values,approximately 76.7% of training rows are missing this feature, we retain the column initially and represent missingness explicitly. Dropping it immediately could discard useful information from the observed values.
For unseen categories we use an encoder configured to handle unknown categories.
